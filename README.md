# 車の試乗予約サイト（Google Apps Script 版）

Google スプレッドシート + Google Apps Script（GAS）+ GitHub Pages で動く、スマートフォン（iPhone 対応）向けの試乗予約サイトです。
サーバー契約や費用は不要です。

## 機能

- 試乗車を**複数台**登録できます（スプレッドシートで追加・停止）
- 1回の試乗時間は**初期値 40 分**。スプレッドシートの「設定」シートでいつでも変更できます
- **1つの試乗枠には1人だけ**予約できます（同時アクセスでも二重予約しないよう排他制御しています）
- 予約入力項目: **氏名・連絡先（電話番号またはメール）・規約理解のチェックボックス**
- 定休日・休業日・受付時間・予約可能日数・締切時間（何分前まで受付か）を設定可能
- 新規予約時に店舗へ通知メール（任意）。連絡先がメールアドレスならお客様にも確認メールを送信
- 予約データはスプレッドシートの「予約」シートで一覧・管理（キャンセルはステータスを変更するだけ）

## 画面の流れ

① 試乗車を選ぶ → ② 日付を選ぶ → ③ 空いている時間を選ぶ → ④ 氏名・連絡先を入力し、規約に同意して予約 → 予約ID表示

## 構成

```
お客様の iPhone ──▶ GitHub Pages（予約画面 docs/index.html）
                         │ fetch（JSON）
                         ▼
                 Google Apps Script（API: src/Code.gs）──▶ Google スプレッドシート
```

予約画面は GitHub Pages に置き、Apps Script は JSON API として使います。
Apps Script の URL を画面として直接開くと、**複数の Google アカウントでログイン中のブラウザ（特に iPhone）で
「現在、ファイルを開くことができません」と表示される** Google 側の既知の問題があるため、この構成にしています。

| ファイル | 内容 |
| --- | --- |
| `src/Code.gs` | API（枠計算・予約登録・二重予約防止・メール送信・初期設定） |
| `src/appsscript.json` | GAS のマニフェスト（タイムゾーン: Asia/Tokyo、Web アプリ設定） |
| `docs/index.html` | 予約画面（スマホ向けUI）。GitHub Pages で公開 |
| `docs/config.js` | Apps Script のウェブアプリ URL を設定するファイル |

## 導入手順

### 1. スプレッドシートと Apps Script
1. [Google スプレッドシート](https://sheets.google.com) で新しいスプレッドシートを作成し、**拡張機能 > Apps Script** を開く
2. `コード.gs` の中身を全て消し、`src/Code.gs` の内容を貼り付けて保存
   （以前の版で作った `index.html` ファイルが Apps Script 側にあれば削除して構いません）
3. 関数 `setup` を選んで「実行」し、権限を許可 →「設定」「試乗車」「予約」シートが作成されます

### 2. Apps Script を API として公開
1. **デプロイ > 新しいデプロイ > ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（「Google アカウントを持つ全員」ではありません）
2. 表示された **ウェブアプリ URL**（`/exec` で終わる）を控える

> コードを修正したときは **デプロイ > デプロイを管理 > 編集（鉛筆）> バージョン: 新バージョン** で更新します（URL は変わりません）。
> 「新しいデプロイ」を作り直すと URL が変わるので、その場合は `docs/config.js` も書き換えてください。

### 3. 予約画面を GitHub Pages で公開
1. `docs/config.js` の `API_URL` に、手順2の URL を設定してコミット
2. GitHub のリポジトリ画面で **Settings > Pages** を開く
3. 「Build and deployment」の Source を **Deploy from a branch** にし、
   Branch に公開するブランチと **`/docs`** フォルダを選んで **Save**
4. 1〜2分後、ページ上部に表示される URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が予約サイトです
5. iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」するとアプリのように使えます。
   QRコードにして店頭・チラシに掲載するのもおすすめです

「設定」「試乗車」シートの変更は再デプロイ不要で即時反映されます。

## 運用方法

### 設定（「設定」シート）

| 項目 | 初期値 | 説明 |
| --- | --- | --- |
| 店舗名 | ○○モータース | 画面上部に表示 |
| 店舗電話番号 | 00-0000-0000 | 予約完了画面・確認メールに表示 |
| 試乗時間（分） | 40 | 1回の試乗時間 |
| インターバル（分） | 10 | 枠と枠の間の準備時間（0 なら連続） |
| 受付開始時刻 | 10:00 | 最初の枠の開始時刻 |
| 受付終了時刻 | 18:00 | この時刻までに終わる枠まで作成 |
| 予約可能日数 | 14 | 今日から何日先まで予約できるか |
| 締切（分前） | 60 | 開始の何分前まで予約できるか |
| 定休日（曜日） | 水 | `水,木` のようにカンマ区切り |
| 休業日 | （空欄） | `2026-12-31,2027-01-01` のようにカンマ区切り |
| 通知先メール | （空欄） | 新規予約の通知先。空欄なら通知なし |
| 利用規約 | サンプル文 | 予約画面に表示する規約。自由に書き換えてください |

初期値の場合、枠は 10:00 / 10:50 / 11:40 / … / 16:40 の 9 枠になります。

### 試乗車（「試乗車」シート）

| 車両ID | 車名 | 説明 | 画像URL | 受付中 |
| --- | --- | --- | --- | --- |
| CAR01 | サンプルセダン | ハイブリッド / 5人乗り | （任意） | ☑ |

- 行を追加すれば試乗車が増えます。**車両ID は重複しないように**してください
- 「受付中」のチェックを外すと、その車は予約画面に表示されなくなります
- 画像URL は公開されている画像の URL を指定（空欄ならアイコン表示）

### 予約（「予約」シート）

- 予約が入ると1行追加されます（予約ID・日時・車・氏名・連絡先・規約同意・ステータス）
- **キャンセル**: 「ステータス」を `キャンセル` にすると、その枠は再び予約可能になります
- **枠を手動でふさぐ**（店頭予約・点検・昼休み等）: 行を追加し、試乗日（`2026-10-25`）・開始・終了・車両ID を入力し、ステータスを `予約` にします
- 二重予約の判定は「同じ車・同じ日で時間が重なるか」で行うため、途中で試乗時間を変更しても既存の予約と重なる枠は自動的に予約不可になります

## セキュリティ・個人情報について

- 予約画面には空き状況のみを返し、他のお客様の氏名・連絡先は一切表示しません
- 予約データはスプレッドシートの所有者（店舗）だけが閲覧できます。スプレッドシートを共有する範囲にご注意ください
- 入力値は数式として解釈されないよう処理して保存しています
